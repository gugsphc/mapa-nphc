# Modelos de organização funcional do encéfalo na NPHC

Mapa 3D interativo do encéfalo que reúne as zonas corticais de Grigori Poliakov, as unidades funcionais e os fatores de Aleksandr Luria e os gradientes de Elkhonon Goldberg.

**Abrir o mapa:** https://gugsphc.github.io/mapa-nphc/

**Usar sem internet:** baixe [mapa-nphc.zip](https://gugsphc.github.io/mapa-nphc/mapa-nphc.zip) (arquivo único, ícone e atalho para Windows) ou só o [mapa-nphc.html](https://gugsphc.github.io/mapa-nphc/mapa-nphc.html). O arquivo baixado avisa quando houver versão nova.

Síntese conceitual, desenho e elaboração: Gustavo Figueredo Pio, psicólogo (CRP 11/25112).
Revisão técnica: Prof. Dr. Hansel Soto Hernández.

## Versões

- **1.1 · 26/11/2026**: menu do modelo reorganizado em Zonas (Poliakov), Modelos de Luria (unidades, fatores, sistemas), Anatomia (Brodmann) e Gradientes (Goldberg); montar um sistema (ideia do Prof. Dr. Hansel Soto Hernández): escrever a tarefa, acumular os fatores no modelo, organizar etapas, fundo e retorno, comparar com os sistemas do mapa, compartilhar por link e enviar como proposta; papéis distintos do fator de programação nos sistemas (início, verificação com retorno, fundo); variante de escrita espontânea; páginas do HCF conferidas.
